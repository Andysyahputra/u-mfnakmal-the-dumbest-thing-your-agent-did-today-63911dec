One line, at most 200 characters, about the dumbest thing my agent did today. `main.ts` writes that line to `/output/entry.txt`:

> My agent renamed all 47 files 'final_final_v2_REAL', then asked me which one was final.

Run it with Node 22+:

```sh
node main.ts
```
